## Local reproduction and safeguards

The isolated build is `build-p2-fsr`, configured with SDL3, native Vulkan, Portal 2,
FSR enabled, and both physics providers. Rebuild from this checkout:

```sh
systemd-run --user --scope --slice=source-fsr.slice --quiet \
  env WAFLOCK=.lock-waf-p2-fsr python3 waf build -j12 -o build-p2-fsr
```
